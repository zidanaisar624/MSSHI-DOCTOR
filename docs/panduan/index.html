MSSHI DoctorPanduan lokal

Apa yang terjadi pada Hermes?

Pilih gejalanya untuk melihat pemeriksaan pertama. Jalankan perintah dari PowerShell di folder MSSHI-DOCTOR yang sudah diekstrak.

Pilih situasi

Periksa instalasi lokal

Buka aplikasi Doctor atau lihat ringkasan profil, lokasi instalasi, dan kondisi file dari terminal.

.\msshi-doctor.cmd --local

Periksa lokasi instalasi yang ditampilkan sebelum memilih langkah berikutnya.

Baca hasil pemeriksaan

Buat laporan dengan perintah berikut, lalu pilih file JSON-nya. Isi laporan diproses di browser pada perangkat ini.

.\msshi-doctor.cmd --local --json | Out-File -Encoding utf8 doctor.json
